# Knowledge-Aware Conformance Checking: Proof-of-Concept

Proof-of-concept tool of the master thesis *Knowledge-Aware Conformance Checking: Integrating Object-Centric Event Data and Behavioral Constraints for Process Diagnosis in SAP* (Utrecht University,
2026, in cooperation with Emixa).

The tool lets you explore the Knowledge Graph of a Purchase-to-Pay process, run OCBC conformance
queries (SPARQL) on it, see the model-wide conformance, and generate a natural-language
explanation of the detected violations with an LLM (Claude, via the Anthropic API).

- **Knowledge Graph view:** the graph as an interactive network of Purchase Orders and their
  Requisitions, Goods Receipts, Invoices and Financial Documents. Violations are highlighted.
- **SPARQL and AI explanation view:** select one of the nine constraints, execute its query,
  inspect the violations and generate an AI diagnosis.
- **Model-wide conformance:** the conformance score, the number of conformant and violating
  Purchase Orders and a breakdown per query.

The scripts that build the graphs and run the evaluation are in the replication package: https://github.com/R-RVDV/knowledge-aware-process-conformance-framework.

## Repository layout

```
.
├── main.py          FastAPI backend: loads the graphs with rdflib, runs the queries,
│                    calls the Anthropic API
├── data/
│   ├── emixa_p2p_ocedd.ttl      OCEDD: the domain schema
│   ├── ocedr_p2p_graph.ttl      OCEDR: the Knowledge Graph
│   └── injected/                graphs with synthetic violations (one per constraint, plus ALL)
└── frontend/        React + Vite app; src/App.jsx and src/queries.js are the project files,
                     the rest is the standard Vite template
```

## Requirements

- Python 3.11 or newer (developed with 3.11.3)
- Node.js (developed with v24.13.1)
- An Anthropic API key, for the AI explanations. Use your own key
  (https://console.anthropic.com). It is read from the environment variable
  `ANTHROPIC_API_KEY` and is never stored in this repository. Each explanation is an API call
  that is billed to your key.

## Run

Start the backend first, in the repository root. Install the dependencies, set your API key and
start the server:

```
# Windows PowerShell
pip install -r requirements.txt
$env:ANTHROPIC_API_KEY = "your-api-key"
uvicorn main:app --reload --port 8000
```

Optional: to keep the dependencies separate from your other Python packages, first create and
activate a virtual environment (`python -m venv .venv`, then `.venv\Scripts\Activate.ps1`).

Then start the frontend in a second terminal:

```
cd frontend
npm install        # first time only
npm run dev
```

Open the URL that Vite prints (by default http://localhost:5173). The frontend expects the
backend on port 8000.

## Notes

- The AI explanations are generated by an LLM and are meant as an aid. Check them against the
  graph: in the thesis evaluation, experts flagged incomplete or overly general parts of an
  explanation, but accepted its plausible-sounding explanation of the cause without
  questioning it (see the section on the LLM explanation layer).
- The data comes from a test system (VD9) of Emixa and has been anonymised.
- The graphs in `data/injected/` contain synthetic violations that were added to verify the
  queries; they are not real findings.
- The code was developed with the help of generative AI (Claude, Anthropic).
